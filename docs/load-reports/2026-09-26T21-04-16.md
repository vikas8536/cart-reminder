  degree — 250/s). Each `cart-events` record costs a synchronous Redis Lua `EVALSHA` plus a conditional
  DynamoDB Local write, with only 2 detector replicas sharing this one 12-core/7.75 GiB Docker Desktop
  VM alongside 8 other role containers, Kafka, and DynamoDB Local's own JVM.
